Admins

Full edit access to the whole site. This is separate from Legal Hub Access — someone here can change anything in the admin panel, not just view restricted content. Adding someone here does not create their login. They still need an actual account created first via Supabase Dashboard → Authentication → Users → Add user (magic-link sign-in deliberately cannot create new admin accounts on its own — that's intentional, so adding an email here is the second step, not the first).
